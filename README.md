**Aetherbound: Runes of the Void** — An original tactical arcane card duel game where players channel 4 elemental disciplines (Solar, Lunar, Verdant, Void) to outmaneuver an intelligent opponent AI in a battle for arcane supremacy.

## Features
- **4 Elemental Disciplines**: Solar (Ruby Strike & Burn), Lunar (Sapphire Ward & Freeze), Verdant (Emerald Surge & Poison), and Void (Amethyst Flux & Chaos).
- **Tactical Combos**: Chain complementary elements for devastating elemental synergies and momentum surges.
- **Dynamic Arcane Arena**: Beautiful dark fantasy HTML5 Canvas rendering with glowing runic circles, dynamic particle bursts, and floating damage numbers.
- **Procedural Sound Engine**: Synthesized Web Audio API effects for card deals, elemental blasts, shield hums, and victory flourishes.
- **Tactical Opponent AI**: Evaluates lethal threat, mana efficiency, defensive wards, and multi-card combos.
- **Offline & Zero Dependencies**: Fully self-contained static HTML5 / ES modules running offline with zero external network requests.

## Run it

```sh
node serve.ts 8080
```
Then open `http://localhost:8080` in your desktop browser.
